1. Open Terminal and cd into folder in which Files are downloaded.
   - ex cd Downloads
2. Run commands
   - chmod +x setup-immich-mac.sh
   - chmod +x uninstall-immich-mac.sh
   - ./setup-immich-mac.sh
3. The last command will run the setup.
4. Go through Dialogs
5. If Uninstall Run
   - ./uninstall-immich-mac.sh
